# 战役动作（第四期 4c）

46 场已逐场核对，35 场有适用的增补：新增 62 个动作（围城 33、水攻 4、断粮道 4、水战 17、寨堡 3、兵力变化 1），另有 13 场战前布势；五路伐夏原有的围城样例保留。只新增 steps[][1] 中的动作和战役 pre，原步骤、原动作、侧栏、讲稿与配音保持不变。下列“步骤”均从 1 起算。

动作：s 围城、w 水攻、k 断粮道、n 水战、f 山城/寨堡、v 兵力变化；pre 战前布势。新动作非当前步只保留图形，标注不累积、无动画。k 只影响当前步，v 随步骤重放，回退恢复原兵力；坐标与水斑是战术示意，不作淹没范围或真实决口定位。
