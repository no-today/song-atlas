# 路线出处（第四期 4b 首批）

本批按明确下标处理 **15 条**：1、2、3、26–30、38–41、61、64、65。任务文字称 16 条，但列举合计为 15 条；未自行增补。`data/route-waypoints.json` 的键是数组下标，值为城邑名或 `[经度,纬度]`；旧路线的首尾坐标另由工具锁定，不从近似经纬度重建。

- **1 平后蜀北路**：凤州循嘉陵江上游至兴州、三泉，再取明月峡—利州—剑门，接梓潼、绵州、德阳至成都。《宋史》[卷255](https://zh.wikisource.org/zh-hans/宋史/卷255)记兴州、三泉、修阁道、深渡、利州、桔柏江及剑门；来苏是分兵迂回，不能用单条主线同时表达正攻与绕后，未另造支线。三泉、明月峡及剑门以南具体谷道约略。
- **2 平后蜀东路**：归州起，经长江三峡、夔州、万州、忠州，再循川中低地趋遂州、成都方向。《宋史》[卷259](https://zh.wikisource.org/zh-hans/宋史/卷259)记先舍舟夺夔州桥，再水陆合击，继取万、施、开、忠、遂州；本线兵种为混，不把全部行程解释为水军。忠州至遂州的县道与分兵合流位置约略，保留原终点（成都东南，非成都城标）。
- **3 平南汉**：潭州经湘江—潇水低地、道县—江华—富川通道入贺州，取昭、桂后东折连州、韶州，再循北江趋广州。《宋史》[卷258](https://zh.wikisource.org/zh-hans/宋史/卷258)明载“进克富川”，[卷481](https://zh.wikisource.org/zh-hans/宋史/卷481)载贺、昭、桂、连、韶及英雄诸州；[贺州学院《潇贺古道富川段的文化遗存》](https://mks.hzxy.edu.cn/info/1036/1366.htm)说明潇贺古道谷地及陆路走向。越岭采用有富川节点支持的潇贺通道，未强加骑田岭道；具体隘口、昭桂两地分兵与再会合约略，单线代表战役推进顺序，并非一支部队逐城实走的证明。
- **26 五路伐夏熙河路**：熙州北趋兰州，再沿黄河谷地东进，越低鞍至天都山方向。《宋史纪事本末》[卷40](https://zh.wikisource.org/wiki/宋史紀事本末/卷40)、《宋史》[卷467](https://zh.wikisource.org/wiki/宋史/卷467)载取兰州、焚南牟宫、馈饷不接；兰州以东具体山口与天都山、南牟宫定位约略，沿用原终点。
- **27 五路伐夏泾原路**：原起点在今固原附近，循清水河走廊北进灵州方向，强制通过既有步骤的磨脐隘标点。《宋史》[卷349](https://zh.wikisource.org/wiki/宋史/卷349)作磨齐隘，[卷486](https://zh.wikisource.org/wiki/宋史/卷486)作磨脐隘；未查得足以确定关隘精确经纬度的依据，借用旧图标点，不将其说成测定位置。注意原起点并非渭州城标。
- **28 五路伐夏环庆路**：庆州向西北循环江水系及支谷，出山趋灵州南缘。《宋史》卷349、486载环庆军后至、围灵州及七级渠败退；具体分水岭山口、各谷衔接约略，不借后世道路充当行军史证。
- **29 五路伐夏鄜延路**：延州经延河支谷北上，至米脂转入无定河，过银州西取夏州。《宋史》[卷335](https://zh.wikisource.org/wiki/宋史/卷335)、卷486载米脂交战、克银石夏；谷道由 DEM 约束，银州至夏州的分兵与石州支线未用一条主线强行展开。
- **30 五路伐夏河东路**：原起点在府州方向，经鄂尔多斯东南部沟谷向宥州。《宋史》卷467、《本末》卷40载河东军入宥州、粮道不继；越黄河的具体渡口、入宥州前所循沟道约略，未将小说中的磨脐隘描写作为依据。
- **38 富平宋军**：秦州循渭河谷地东下，沿秦岭北麓至富平南缘。《宋史》[卷361](https://zh.wikisource.org/wiki/宋史/卷361)、[卷366](https://zh.wikisource.org/wiki/宋史/卷366)载召陕西五路兵会富平；该线仅代表五路会师中的西向来军，不表示五路均从秦州出发。具体渡口、集结营地约略。
- **39 富平兀术军**：洛阳经崤函低通道、陕州、潼关入渭河平原，西趋下邽方向。《宋史》卷366及《金史》[卷72](https://zh.wikisource.org/wiki/金史/卷72)所载陕西战事为依据；洛阳至下邽之间的细部驿道约略，保留旧终点，不移会战标记。
- **40 富平娄室军**：自原起点沿洛河下游及渭北低地南进，与兀术会师。《金史》卷72、《宋史》卷366载娄室与兀术攻陕西、富平会战；北侧具体出发营地与渡口无足够依据，保留旧起点，谷道约略。
- **41 和尚原金军**：原起点凤翔，经宝鸡附近渭河低地，循清姜河谷趋大散关方向。《宋史》卷366载自宝鸡攻和尚原；和尚原遗址与旧图终点不能等同，末段及关口位置约略。1134 年仙人关攻势是步骤中的内嵌 `a` 路径，不在本批可修改字段内，仍保留原样。
- **61 阔端入蜀**：巩昌经秦州、陇州、宝鸡—大散关方向、凤州—留坝—褒河马道段至兴元，循汉水至旧图阳平关，再向蜀中。《宋史》[卷449](https://zh.wikisource.org/zh-hans/宋史/卷449)载破武休、败宋军、入兴元、趋大安与鸡冠隘战；《元史》[卷2](https://zh.wikisource.org/zh-hans/元史/卷002)载入成都。北段衔接、阳平关旧点与鸡冠隘的关系，以及本次是否确经利州、剑门，均约略；后两节点沿既有地图叙事保留，不当作本传确载（见项目《战役出处-bat-e.md》已有核查）。
- **64 蒙哥主力**：六盘山经陇州、宝鸡、大散关、凤州、汉中入蜀，利州—剑门—苦竹隘后向大获、青居、钓鱼城推进，川北至合州段沿嘉陵江谷。《元史》[卷3](https://zh.wikisource.org/zh-hans/元史/卷003)记上述行军与山城节点，卷155载渡嘉陵、白水架浮梁；具体小路和桥位约略。大获等山城本在高处，到达城标须离开河谷，不能据此把整线强制压在河心。
- **65 宋援舟师**：重庆溯嘉陵江向合州，截取 `base.rivers` 中实际连接两端的嘉陵江子路径，保留原起终点。《元史》[卷155](https://zh.wikisource.org/zh-hans/元史/卷155)载宋舟师、嘉陵江及败退重庆；三槽山名称与旧图标点未有同等强度的原文依据，未强行将河道拉离谷底去经过会战星标。底图河道经过概化，与现代 DEM 河槽仍可能有偏差。

## 重算和核验

运行环境为主检出的 `.cache/venv`（依 `tools/relief-requirements.txt`），DEM 只读主检出的 `.cache/dem`，不联网补下载。陆路代价在 `tools/route-trace.py` 文件头列出。途经点连接的是地形代价最小路径；这只能约束合理走廊，不能证明古代道路的精确线位。

步骤比例按 main 旧路径的长度位置映射：附近有控制点时吸附控制点，否则投影到新线最近点；相同旧比例只计算一次，保留三位小数，0、1 不变。工具逐字段核对 events，仅允许本批 `m` 动作的起止比例变化，并检查相邻动作衔接。它也锁住路线顺序、非 path/标注字段、原首尾和 120 点上限。`tools/data.mjs` 为白名单读取，途经点表不装入成品。

注意：旧比例自身已有语义误差，最近位置映射不会自动修正它。例如平后蜀北路旧 0.7 已在剑门以南，不能同时满足“保留旧位置映射”与“该步箭头恰停剑门”两个要求。现遵守前者；未擅改步骤、文字、语音或内嵌 `a` / `r` 路径。旧端点与成都、和尚原、广州、钓鱼城、灵州等城标不完全重合的问题也受端点锁定约束。

验证及数值如下。图像自查发现汉中以北的初选控制点会形成回钩，已依据[留坝县政府的马道镇说明](http://www.liuba.gov.cn/lbxzf/xzqy/202312/fb6c9acb81994312b2d7768157015675.shtml)及[马道镇坐标](https://zh.wikipedia.org/wiki/马道镇_(留坝县))，改以褒河马道段控制走廊，移去无依据的东侧控制点。武休关在武关河与褒河汇合处半山腰的定位参见[冯岁平《武休古关今尚在？》](https://edt.cqvip.com/v2/journal/sxlgdxxbskb/article/580261472)，其精确关址仍未拿任意近似点冒充。
