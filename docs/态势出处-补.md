# 补充九幅疆域态势：史实与表示口径

本次新增 1028、1038、1082、1116、1122、1137、1215、1218、1254 九幅，态势由 25 幅增至 34 幅。全部通过 `data/snap-edits.json` 的 `move` 派生；`snaps.json`、`shapes.json` 仅由 `npm run derive` 写入。原 1073、1125、1227、1273 四条 edits 及对应态势保持不变，1125 仍取自 1111。

年号沿用项目以宋纪年的方式；史料中的辽、金、蒙古纪年另在下文注明。按年显示的态势表示该年事件发生后的概况，不是该年每一月的实控图。所列古籍可据卷次、纪年及引文检索；形状是现有底图上的概括，不能将城邑攻取记录当作精确边界测绘。

## 逐幅依据

### 1028：天圣六年，元昊取甘州（基准 1005）

- [《宋史》卷485《夏国传上》](https://zh.wikisource.org/wiki/宋史/卷485)天圣六年：“德明遣子元昊攻甘州，拔之”；元昊传另记“奪甘州”。当时统治者仍是李德明，元昊领兵，本幅标题不表示元昊已经称帝。
- 操作：`ganzhou` 全部并入 `xia`；凉州六谷部、归义军暂仍分列。
- 边界：沿用甘州回鹘与夏州李氏的旧形状，范围**约略**。甘州与河套两片在旧底图上不接壤，合并后保留两片，不能把断口视为有史料支持的独立政权疆界。

### 1038：宝元元年，元昊称帝，西夏尽有河西（基准 1028）

- [《续资治通鉴长编》卷119](https://www.guoxuedashi.com/a/334j/10371d.html)，景祐三年十二月辛未条，记“再舉兵攻回紇，陷瓜、沙、肅三州，盡有河西舊地”。本幅把 1036 年及此前的河西变化汇总到 1038 年，不表示三州在称帝当年才陷落。
- [《宋史》卷485](https://zh.wikisource.org/wiki/宋史/卷485)列元昊已据“甘、涼、瓜、沙、肅”等州；宝元元年记“築壇受冊，即皇帝位”。
- 凉州取 1032 年的任务口径；[《剑桥中国辽西夏金元史》元昊一节](http://szzy.7lue.cn/read/ec88e139385a08fc2b6a923e591de4d5/8a317d8b5079f213d46a423933ced523.md)亦叙德明去世前元昊已并凉州。所核《宋史》本传没有单列“1032 年取凉州”的逐日纪事，因此不补具体月日。
- 操作：`liugu`、`guiyi` 全部并入 `xia`，名称自本年显式设为“西夏”。甘州已由 1028 幅并入。
- 边界及争议：河西诸州外围与河套连接区均**约略**。瓜沙在 1036 年后是否始终处于西夏有效统治之下，敦煌材料与传世史籍的解释有分歧；[相关史料辨析](https://www.uyghur-archive.com/uighurbiz-cn/article_3461.html)讨论了 1036 年占领与后续统治的区别。本次依任务和《长编》的概括，1038 起不再单列归义军。旧图河西与河套之间的断口未擅自填平。

### 1082：元丰五年，五路伐夏后（基准 1073）

- [《宋史》卷16《神宗纪》](https://zh.wikisource.org/wiki/宋史/卷016)：元丰四年九月“李憲復蘭州古城”，十月丁巳“米脂砦降”；元丰五年九月“永樂陷”。据此把兰州、米脂等战后保留据点划宋，不把短暂攻入的夏州、银州全部划宋。
- [《宋史》卷87《地理志》](https://zh.wikisource.org/wiki/宋史/卷087)：兰州“元豐四年收復”；米脂、义合、细浮图等寨各有元丰四年收复记载，永乐则“旋被西人陷沒”。[《长编》卷317](https://skqs.dazhishi.com/show_bzdarkxpyg.html)元丰四年十月记米脂受降，[卷330](https://skqs.dazhishi.com/show_xnymrbnwdm.html)记次年永乐陷后处置。
- 葭芦的元丰五年收复，参见[陕西师范大学历史文化名城资料《宋军收复葭芦寨》](https://lishiwenhua.snnu.edu.cn/info/1816/11597.htm)；细浮图在今子洲张家寨，参见[克戎寨遗址资料](http://www.tcmap.com.cn/landscape/104/futuzhai.html)。这些材料只用于小范围定位，不代替宋代边界文献。
- 操作：两块 `area` 与 `xia` 相交后划给 `song`：兰州周边一块，米脂—细浮图—葭芦一带一块。兰州与米脂城点已在宋境，银州城点仍在夏境，青唐仍在唃厮啰境。寨堡之间的控制带与外围走向均为**约略**，不声称画出了每一寨的完整辖地。安疆不另画精确突出部，以免用未经定位的坐标扩大划转。
- 时间局限：《宋史》地理志记米脂、克戎等元祐四年给夏，后绍圣、元符间再取；既有讲稿出处记还寨系年另有元祐五年的口径。本次没有新增元祐还寨、绍圣复取两幅，所以 1082—1110 年仍会沿用本幅，不能当成这二十九年从未变化的实控线。既有 1073 与 1111 两幅自身也不是严格嵌套的形状，本次不改它们。

### 1116：政和六年，金取辽东（基准 1111）

- [《金史》卷2《太祖纪》](https://zh.wikisource.org/wiki/金史/卷2)，收国二年（1116）闰月高永昌据东京，五月金军败永昌，“東京州縣及南路系遼女直皆降”。
- 操作：仅从 `liao` 划取辽阳以东、以北及辽东南部连接地带，包含辽阳与会宁城点。此项目的辽形状已覆盖生女真故地；这里沿用的是几何容器，不表示所有生女真原本都受辽直接统治。**没有使用 `set`，没有额外向辽形状之外扩地**。
- 边界：由辽阳以西一线向东北延伸，依据诸州、女真归附的概括画为**约略**。不是辽东京道各州县的精确行政界，也不把辽西在随后数年陆续陷落的土地全部提前并入。

### 1122：宣和四年，金取辽中京、西京（基准 1116）

- [《金史》卷2](https://zh.wikisource.org/wiki/金史/卷2)，天辅四年（1120）取上京；天辅六年（1122）正月取中京，三月西京降后复叛，四月复取西京，十二月取居庸关、入燕京。
- [《辽史》卷29《天祚纪》](https://zh.wikisource.org/wiki/遼史/卷29)，保大二年金军取中京、天祚西走，可与金纪相参。辽廷此后仍存，不能在本幅删去 `liao`。
- 操作：由 `liao` 再划中京、西京、燕京及其北面已失地区给 `jin`，辽保留西北；返工把西缘 `[111.3,40.5]` 移至 `[110.8,40.5]`，补入云内、东胜。《金史》卷2天辅六年四月记招降天德、云内、宁边、东胜等州。阴山、夹山与漠北之间的残余控制范围为**约略**；本幅是 1122 年末概况，不将当年耶律淳、萧德妃、萧干等残余势力逐一另建政权。
- 与 1125 衔接：1116→1122，金的已有范围全部保留；1122→1125，东北部分仍全部留金。1125 仍按原 edit 从 1111 派生，燕京一带转宋，符合 1123 年交燕地的处理。这是明确的转属，不是金在辽东缩回去；除此以外，布尔运算序列化只有不足 1 图上平方单位的细边差。
- 已知时序：本次没有 1123 幅，故 1123—1124 年仍显示 1122 年末燕京属金，直到原 1125 幅才显示属宋。“赎回燕京”事件与截图 y1123 的这个两年错位仍保留，不能声称已解决。

### 1137：绍兴七年，金废伪齐（基准 1131）

- [《金史》卷4《熙宗纪》](https://zh.wikisource.org/wiki/金史/卷4)，天会十五年十一月丙午：“廢齊國，降封劉豫爲蜀王……置行台尚書省爲汴”。[《宋史》卷365《岳飞传》](https://zh.wikisource.org/wiki/宋史/卷365)记绍兴四年（1134）收复襄阳六郡，包括唐、邓；唐、邓不能随 1131 年基准中的伪齐疆域一并转金，至 1142 绍兴和议才割给金。
- 操作：先用 `[[111.7,31.8],[111.7,33.1],[112.4,33.2],[113.25,33.1],[113.35,31.8]]` 与 `qi` 相交，把唐、邓一带划给 `song`；再将 `qi` 剩余地全部并入 `jin`。已核唐、邓与襄阳连为宋境，洛阳、蔡州仍属金；不是在金并齐后从整片金境中任意切宋地。
- 边界：沿用原宋齐、金齐轮廓，仍为**约略**。1138—1141 年河南、陕西数度易手，此次没有新增中间攻守态势。1137 幅不会再在 1140 年把伪齐画成仍存的政权。

### 1215：嘉定八年，蒙古取中都（基准 1208）

- [《元史》卷1《太祖纪》](https://zh.wikisource.org/wiki/元史/卷001)，八年（1213）三路进兵，有沿海取蓟、平、滦、辽西诸郡的记载；十年（1215）取北京（辽中京大定府）、兴中，中都于五月庚申陷，随后又记平州、广宁归附。
- [《金史》卷14《宣宗纪》](https://zh.wikisource.org/wiki/金史/卷14)，贞祐二年（1214）迁南京，三年五月庚申“中都破”。元、金二纪可互证都城陷落的时间。
- 操作：只从 `jin` 划中都、河北北部及辽西带给 `mongol`；不以蒙古曾攻掠、郡县一度投降为由，把全部河北、河东、山东或辽东都一并割入。
- 边界：燕山南麓—河北北缘—辽西的折线为**约略势力范围**。金军与地方武装仍有反复攻守，辽西有降叛，辽东另有耶律留哥、蒲鲜万奴等势力；本次不添加新政权。1215—1218 新得范围在原 1227 幅中基本保留，只有旧形状精度造成的细边差。

### 1218：嘉定十一年，蒙古灭西辽（基准 1215）

- [《元史》卷120《曷思麦里传》](https://zh.wikisource.org/wiki/元史/卷120)：从哲别为先锋，“斬其主曲出律”，以其首徇可失哈儿、押儿牵、斡端诸城，“皆望風降附”。此传能核实征服过程，本身没有把该段明确系到 1218 年。
- [《新元史》卷3](https://zh.wikisource.org/wiki/新元史/卷003)太祖十三年条，记哲别讨屈出律，奔巴达克山被杀，用以互核 1218 年的系年。网页转录将戊寅误作“戊宣”，不可照录其错字。本次核对[《元史》卷1](https://zh.wikisource.org/wiki/元史/卷001)九年甲戌条，未见杀屈出律的记载，原文所谓“本纪另系于九年”属误引，应删除；卷120《曷思麦里传》记征服过程，但未明确系年。1218 年另可参[中国社会科学院历史研究所《元朝的西北各族》](http://lishisuo.cssn.cn/xsyj/gdzwgxs/202001/t20200116_5079095.shtml)“灭西辽”节，并与项目[战役出处-bat-e.md](战役出处-bat-e.md)的事件终点口径相合。
- 操作：`wliao` 全部并入 `mongol`，另将金的河东局部划给蒙古，题仍为“蒙古灭西辽”。[《元史》卷1](https://zh.wikisource.org/wiki/元史/卷001)十三年戊寅条记由西京入河东，取太原、平阳及忻、代、泽、潞、汾、霍等州；[《金史》卷15](https://zh.wikisource.org/wiki/金史/卷15)兴定二年九月至十一月的太原、平阳、潞州失守可互证。河东最终范围为 `[[109.2,40.7],[113.6,40.7],[113.6,35.3],[112.5,35.3],[111.1,35.8],[110.9,39.8],[109.2,40.4]]`，仅与 `jin` 相交。原候选北缘 39.8° 与 1215 蒙古形状间存在金地窄带，直接采用会使河东变成孤片；北端遂接到西京一线，并沿西夏东北缘收掉会残留为孤片的金地窄角，未改西夏形状。太原、平阳、忻、代、汾、泽归蒙古，河中、开封仍归金，蒙古与金各自保持连通。河东周边及连接带仍为**约略势力范围**，不将攻取州府等同于精确驻治界线；西辽形状同样是核心与势力范围的综合概括，不等同于随后征服的整个中亚。
- 高昌回鹘 1209 年归附的史实见《元史》卷1“四年己巳春，畏吾兒國來歸”。本次返工仅补河东，不处理高昌回鹘，且原 1227 edit 不改，故高昌回鹘在 1215、1218 两幅仍单列，到 1227 才并入；这是保留的时间粒度局限。

### 1254：宝祐二年，蒙古灭大理（基准 1234）

- [《元史》卷3《宪宗纪》](https://zh.wikisource.org/wiki/元史/卷003)，三年癸丑（1253）十二月“大理平”；四年甲寅（1254）记忽必烈回师、留兀良合台攻未附诸部。
- [《元史》卷121《兀良合台传》](https://zh.wikisource.org/wiki/元史/卷121)甲寅秋取善阐、转攻押赤，至昆泽擒段兴智；故本幅依任务以 1254 年擒王为节点，区分 1253 年都城陷落与后续征服。传文至乙卯仍有平诸部记载，不能把全境着色解释成 1254 年所有山地寨部都已完成逐一驻治。
- 操作：`dali`、`tibet` 全部并入 `mongol`；南宋仍沿用 1234 幅，不提前复制 1260 幅中成都、汉中等宋地的失守。
- 吐蕃取舍：已对照 1260 幅，该幅没有独立的 `tibet`，以蒙古统一着色。本幅沿用这个表示口径，将此前陆续归附汇总于此。1247 年凉州会谈及萨班《致蕃人书》、1254 年忽必烈《优礼僧人诏书》的关系，可参[中国藏学研究中心张云的研究](http://www.tibetology.ac.cn/2018-05/02/content_41699232.htm)和[凉州会谈专题](http://www.tibetology.ac.cn/2021-05/02/content_41699234.htm)。[《元史》卷202《释老传》](https://zh.wikisource.org/wiki/元史/卷202)可核八思巴与忽必烈的联系及中统元年授国师，但不能据此独自推出 1247 年一条明确的全高原疆界。
- 这里表示归附关系逐步形成，不表示吐蕃诸部在 1254 年忽然同时被军事征服。高原外围、大理南境及山地部族控制线均为**约略**。旧底图在昆仑山附近的细小无主地孔洞继续保留，不能用不明归属的补面硬填。

## 独立复核：已证实的城邑问题与待考范围

以下保留 `7a5c265` 提交时的复核记录与候选经纬度；其中“当前”指当时尚未返工的图。该次复核未改 snap-edits、snaps、shapes，文字改动仅涉及 narrative 与本文件。**本次随后已处理云内、东胜，唐、邓，以及河东三项，实施结果见文末“三处返工记录”**；其余候选不在本次改动范围。城点通过 `node tools/geo.mjs city 名称` 查询，再按实际投影检查生成形状的归属；候选线只用于纠正城点，不是考订完成的行政边界。

- **1028 肃州提前划夏。** 肃州城点（98.50,39.75）随 `ganzhou` 全并而入夏，但《长编》卷119把陷瓜、沙、肃三州附于景祐三年（1036）。1028 年的攻取甘州不能推出肃州也已入夏，故 narrative 的“甘州回鹘故地并入党项”改为“党项据有河西重镇”。建议 1028 的划转先限制在 99.5°E 以东，例如 `[[99.5,36],[103,36],[103,42],[99.5,42]]` 与 `ganzhou` 相交，保留肃州回鹘余部，至 1038 再并其余地。
- **1122 漏云内、东胜，并提前画入部分辽西州府。** [《金史》卷2](https://zh.wikisource.org/wiki/金史/卷2)天辅六年四月明记招降天德、云内、宁边、东胜等州；当前云内（111.19,40.60）、东胜（111.19,40.27）仍在辽。可先把西缘顶点 `[111.3,40.5]` 改到 `[110.8,40.5]`，再核天德、宁边。反之，《金史》卷2及[《辽史》卷29](https://zh.wikisource.org/wiki/遼史/卷29)把平州降、宜锦等州降及兴中府降系于次年正、二月；当前平州（118.89,39.90）、锦州（121.12,41.10）、兴中（120.44,41.57）已划金，不能直接用年末概况解释。建议先在现有划转范围扣去 `[[118.4,39.5],[121.6,39.5],[122.0,41.9],[120.0,42.0],[118.4,41.0]]` 一带并复核诸州降叛，1123 再另表变化；此候选范围避开燕京及中京大定府，不能当作辽西所有州县的准确界线。
- **1137 唐、邓不应随伪齐并金。** 唐州（112.82,32.70）、邓州（112.08,32.68）当前均由 `qi` 转 `jin`。[《宋史》卷365《岳飞传》](https://zh.wikisource.org/wiki/宋史/卷365)记绍兴四年（1134）收复襄阳六郡，包括唐、邓，不能把 1131 的归属直接带到废齐之年。建议补划宋的局部候选为 `[[111.7,31.8],[111.7,33.1],[112.4,33.2],[113.25,33.1],[113.35,31.8]]`；含唐、邓并接襄阳，避开洛阳、蔡州。其余襄阳、随、郢、信阳城点原已在宋。
- **1215 辽阳留金不能直接判为正确。** [《元史》卷149《耶律留哥传》](https://zh.wikisource.org/wiki/元史/卷149)明记“乙亥，留哥破東京”，即 1215 年；当前东京辽阳（123.16,41.27）仍在金。可围绕 `[[122.9,41.1],[123.4,41.1],[123.5,41.6],[123.0,41.6]]` 另核东辽或附蒙势力的表示，不能仅向东扩大蒙古直辖色块。金在东北其他地区尚有据点，不等于仍稳据东京。中都（116.39,39.90）、大同（113.30,40.08）实际均在蒙古，太原、开封仍在金，这四个城点未见本幅划错。
- **1218 漏河东当年进展。** [《元史》卷1](https://zh.wikisource.org/wiki/元史/卷001)十三年戊寅条记蒙古军自西京入河东，克太原、平阳及忻、代、泽、潞、汾、霍等州；[《金史》卷15](https://zh.wikisource.org/wiki/金史/卷15)兴定二年九月下太原、十月下平阳、十一月收潞州可互证。当前因全沿 1215 北方轮廓，这些城点仍留金。建议另补河东局部划转，候选 `[[110.9,39.8],[113.6,39.8],[113.6,35.3],[112.5,35.3],[111.1,35.8]]` 包含太原（112.54,37.87）、平阳（111.52,36.08）、忻、代、汾、泽城点，避开河中、开封；仍须沿山川核潞、霍及外围，不宜照矩形圈地。
- **保州系年及高丽边界须分开处理。** 当前 1116、1122 及后续图把鸭绿江畔保州（124.49,40.20）和义州（124.52,40.20）画在金，二者实际上是先后名称。[《金史》卷135](https://zh.wikisource.org/wiki/金史/卷135)记金攻城而“高麗兵已在城中”；《高丽史》卷14睿宗十二年三月（1117）记来远、抱州归附，改抱州为义州，并以鸭绿江为界（[韩国国史编纂委员会相关注释](https://db.history.go.kr/diachronic/level.do?levelId=jo_020_0010_0010_0180)）。1116 具体归属需处理两书系年差异，不能径断；1122 再画作金则不合。后者可先检查 `[[124.4,40.1],[124.65,40.1],[124.65,40.35],[124.4,40.35]]` 内的两城点，改属高丽，实际线应依鸭绿江核定。
- **其余时间粒度与证据限度。** 1028、1038 仍保留约 1006 年已亡的于阗；1215、1218 高昌回鹘仍单列，若表示实控或内政自治可以区分，但不能因此表示它到 1227 才归附蒙古。1254 吐蕃诸部陆续归附可成立，现有史料尚不足以推出 `tibet` 整片（尤其古格与外围）在该年均有同一程度的蒙古管治；瓜沙 1036 后的持续有效统治也仍需保留前述争议。以上不据概括叙述擅自画出新边界。

- 在本机无头 Chrome 中以 `file://` 打开构建产物，逐年调用 `userYear()`，清除过渡高亮，再设 `view={cx:W/2,cy:H/2,k:1};commit()` 截全图，未启动开发服务器。截图年份：1030、1038、1100、1120、1123、1140、1216、1220、1255。

- `derive` 的现有操作够用以完成九幅划转，但没有“在多边形集合上仅填指定孔洞、保留其他边界”的操作。`set` 会替换整片政权且从其他政权扣除，不适合无依据地修补这些断口；工具按约束未改。未来若要填补，应先核实空白区域的史实归属及既有基准图，而非只改工具来掩盖。

- 1005 基准中的于阗会继续出现在 1028、1038 幅，直到原 1044 幅才消失；唃厮啰也到原 1044 幅才单列。这是严格沿用指定基准、仅执行指定变动的结果，本轮未另改这些政权。
