## 核后留意

- 清单末尾原先以 events 充据的“拓地二千余里”已判 ✗ 并从讲稿删除。原清单没有另立的“请核对的人留意”段，本轮连同其他缺登记事实一并核查。
- 元昊称帝年龄：《宋史》卷485直记“时年三十”，但同卷又记1048年卒“年四十六”，相互不合。此条按原文相符记 ✓，暂保留“三十”，供 Manager 决断；不把史料内部冲突算成无法取原文的 ?。
